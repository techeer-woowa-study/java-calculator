# java-calculator

## **요구 사항 목록**
기능 요구사항 :
- [x] 쉼표(,) 또는 콜론(:)을 구분자를 기준으로 분리한다.
- [x] 분리한 각 숫자를 더한다.

입력 요구사항 :
- [ ] 빈 문자열 또는 공백은 0으로 취급한다.
- [x] 음수를 입력하면 IllegalArgumentException 예외 발생
- [x] 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용 가능하다.
- [x] 쉼표(,) 또는 콜론(:) 및 커스텀 구분자 이외의 구분자를 입력한 경우 IllegalArgumentException 예외 발생

출력 요구사항 :
- [x] 계산된 합계를 정수로 반환한다.

## **코드 작성중 알게된 자바 문법 공부**
### - quote의 동작  
`Pattern.quote("*")` → 내부적으로 이렇게 변환된다:
```
\Q*\E
```
- `\Q` : 여기서부터
- `\E` : 여기까지는  
- 전부 **리터럴 문자**로 처리해라

#### 정리  
- `quote` = 이 문자열 안에 들어있는 모든 문자를 **정규식 특수문자 의미 없이**, **있는 그대로 처리**  
- 그래서 커스텀 구분자가 `".", "*", "|", "+"` 같이 정규식 특수문자라도 안전하게 쓸 수 있다.

---
### - 테스트 코드 작동 원리
아래 코드가 처음 보는 코드라 의미에 대해 정리함.
```java
assertThat(result).containsExactly("1", "2", "3");
```

의미
- `assertThat`는 AssertJ 라이브러리에서 제공하는 검증 시작 메서드
- `result` → 우리가 테스트하려는 리스트
- `.containsExactly("1", "2", "3")` → 순서까지 포함해서 정확히 이 값들만 들어 있어야 한다는 검증.
  - 리스트 안에 `"1", "2", "3"` 이 이 순서대로, 딱 이 값들만 있어야 테스트 통과.
  - 하나라도 빠지거나, 순서가 다르거나, 값이 더 있으면 실패.

### - 자바 문자열 리터럴

예시 :
```java
String a = "A\nB";
String b = "A\\nB";

System.out.println(a);
System.out.println("---");
System.out.println(b);
```
실행 결과 :
```yaml
A
B
---
A\nB
```
#### - 차이 설명

- `\n` 
  - 👉 실제 엔터(줄바꿈 문자)
  - 메모리에 1글자 저장 (ASCII 10)
  - 출력하면 줄이 바뀜

- `\\n`
  - 👉 그냥 문자 \ + 문자 n
  - 메모리에 2글자 저장 ('\', 'n')
  - 출력하면 그대로 \n 보임 (줄바꿈 없음)

#### - 문자열 계산기 문제와 연결

- 문제 요구사항:
`//;\n1`  
→ `//;` (구분자 선언), 그다음 줄에서 `1` 시작  
→ 여기서 `\n`은 진짜 엔터를 의미

- 하지만 Console.readLine()은 한 줄만 입력 가능  
  - 사람은 //; 치고 엔터 누르면 입력이 끝나서 1을 못 넣음  
  - 테스트도 stdin에 한 줄만 넣을 수 있음  

- 테스트는 꼼수로 이렇게 입력함:
`//;\\n1`  
→ 여기서 `\\n`은 실제 엔터가 아니라 문자 두 개 `\`, `n`  
→ 즉, 사람이 직접 보면 `//;\n1`처럼 보이지만 줄바꿈은 안 됨

- 코드에서 해야 하는 일:  
  `\\n` → 진짜 `\n`으로 바꿔주기  
  그래야 테스트 입력(`//;\\n1`)도 문제 의도(`//;\n1`)처럼 동작함

#### - 최종 정리 문장

- `\n` = 진짜 줄바꿈 문자 (엔터)
- `\\n` = 그냥 글자 `\n` (엔터 아님)
- 문제에서는 `\n`을 원하지만,
- 테스트는 한 줄 입력만 가능해서 `\\n`으로 대신 준다.
- 내 코드는 `\\n`을 `\n`으로 바꿔서 처리한다.
